## 🎯 성과 및 회고
**[성과]**
- 실시간 기능과 대량 데이터 처리를 함께 다루며 기술적 성장 경험
- UX 개선을 위해 사용자 피드백을 빠르게 반영하고 인터페이스 개선 반복
- 소켓 통신으로 인한 데이터 지연 **10% 감소**
- 서버 트래픽 50% 이상 감소
  
<br/>

**[회고]**

- API와 소켓이 하나의 서버에서 작동하는데, 성능 및 확장성 면에서 서버 분리의 필요성을 느낌
- 백그라운드에서 작동 할 경우 타이머나 소켓 부분의 작동이 비정상적으로 작동하는 부분이 있어 아쉬움
